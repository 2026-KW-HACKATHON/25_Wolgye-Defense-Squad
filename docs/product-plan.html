월계밥상 가칭

함께 고르고 함께 채우는 동네 식사 플랫폼

각자의 예산·시간·취향으로 식당을 함께 고르고, 방문자가 확인한 메뉴·가격을 다음 추천에 활용한다.

1 해결할 문제와 대상

광운대 주변에서 공강에 식사하는 2~5명 그룹이 첫 대상이다. 예산과 취향이 달라 결정이 어렵고, 오래된 메뉴·가격 정보 때문에 실제로 갈 수 있는 식당인지 판단하기 어렵다는 가설을 검증한다.

목표: 식당 결정 시간을 줄이고, 동네 가게의 최신 정보가 실제 방문 선택으로 이어지게 한다. 초기에는 주변 식당 20~30곳의 메뉴·가격을 팀이 확보한다.

2 핵심 사용 흐름

방 만들기→카카오톡 초대→각자 조건 입력→최대 3곳 추천→투표·방문→정보 확인·수정↺
기능동작 기준
그룹 참여초대 링크로 입장하고 닉네임을 입력한다. 팀 코드는 보조 수단이다.
개별 조건자연어 한 문장으로 입력하고 해석 결과를 확인한다. 예산·시간·메뉴는 모두 선택 사항이며 미입력 값은 비워 둔다. 명시한 상한·제외 조건은 필터, 취향은 선호로 구분한다. 모호하거나 데이터가 없는 조건은 미확인으로 표시한다. 현재 데모는 규칙 기반이며 LLM 해석은 연동 계획이다.
추천각자 예산에 맞는 메뉴가 있는 식당을 먼저 거르고 선호도로 정렬한다. 메뉴·가격·확인 날짜·예상 시간을 함께 보여준다. 결과가 부족하면 그대로 알리고 조건 조정을 제안한다.
투표‘가도 좋은 곳’을 여러 개 선택한다. 동률이면 예상 소요 시간이 짧은 곳을 우선한다. 투표 중 조건을 바꾸면 후보와 투표를 새로 시작한다.
가게 정보 기여메뉴판 사진 → 메뉴·가격 초안 → 사용자 확인 → 수정 기록. 새 가게는 간판 사진과 위치로 등록을 제안하고 중복·위치를 확인한다.
기여 보상확인된 정보 갱신에 기여 기록과 배지를 준다. ‘내 정보가 다음 추천에 쓰였다’를 보여준다. 꾸미기와 동아리 지도는 후속 확장이다.

3 신뢰를 지키는 기준

  • 가격은 실제 메뉴 단위로 관리하고 출처 사진과 확인 날짜를 붙인다. 확인되지 않은 가격을 확정 사실처럼 추천하지 않는다.
  • 시간은 이동·대기·식사·복귀의 추정치이며 지연 가능성을 표시한다. 알레르기 안전은 메뉴 이름만으로 판단하지 않는다.
  • 사진은 해당 정보의 근거다. 가게 전체의 공식 인증으로 표현하지 않는다. 수정 이력·신고·되돌리기를 제공한다.
  • 개인 예산은 본인과 추천 처리에만 사용하고, 다른 참가자에게는 그룹 요약을 보여주는 방식으로 설계한다.

4 시스템 구성과 API 제안

기존 React·Vite 화면과 Express 서버를 유지한다. 서버가 그룹 조건과 메뉴 데이터를 검증해 후보를 결정하고, AI는 자연어 해석·설명·메뉴판 읽기를 보조한다.

이동 시간중간발표는 고정된 시연 값. 실제 서비스용 도보 경로 API는 지원 범위·요금·품질 비교 후 별도 결정한다.미정

데이터 관계: 그룹 → 참가자·개별 조건 → 추천 회차·후보 → 투표. 가게 → 메뉴·가격 → 증빙 사진·수정 이력. 추천 당시 메뉴 버전을 저장해 투표 중 결과가 임의로 바뀌지 않게 한다.

서버 API 초안: 그룹 생성·참여, 조건 저장, 추천 생성, 투표 저장·마감, 가게 등록 제안, 메뉴 수정 제안. 참가자별 투표를 덮어쓰는 방식으로 중복 클릭을 처리한다. API 키는 서버에서만 관리한다.

5 중간발표 범위와 개발 순서

단계보여줄 결과완료 기준
9월 28일 중간발표그룹·조건·후보·투표·정보 수정이 이어지는 화면 데모API 키 없이 한 브라우저에서 처음부터 끝까지 시연. 가상 식당·참가자·인식 초안을 명시.
중간발표 이후API·DB 선택 확정, 실제 그룹 참여·투표, 메뉴 데이터 확보서로 다른 기기에서 같은 방의 상태와 투표 확인.
10월 8~9일 본선실제 데이터 추천·기여 검증·오류 처리 보완예산 필터, 후보 없음, 수정 이력, 사진 처리, 키 보호 검증.
10월 11~13일 전시주민 사용성 검증과 개선결정 시간·투표 완료율·정보 갱신율 측정.

핵심 시연: 3명이 조건을 입력하고 투표한다. 방문 후 메뉴 가격을 수정한다. 새 추천에서 변경된 가격이 반영되는 장면으로 사용자 기여의 가치를 보여준다.

검토할 결정: 서비스명, DB·사진 저장소, NIM 모델, 도보 시간 제공 방식. 중간발표에서는 실제 카카오 전송·다중 기기 동기화·AI 인식을 구현 완료로 표현하지 않는다.
