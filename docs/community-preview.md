# 월계밥상 커뮤니티 실행 안내

## 실행
1. Node.js 설치 후 `npm install`.
2. `.env.example`을 `.env`로 복사하고 NVIDIA·카카오 REST 키 입력. 비밀키는 Git에 올리지 않는다.
3. 카카오 앱의 카카오맵 사용 설정 ON.
4. `npm run dev` → http://localhost:5173. API는 127.0.0.1:3001.

`npm run build` 후 `npm start`로 http://localhost:3001에서 빌드 화면과 API를 함께 실행할 수도 있다. 기본 서버는 루프백에서만 수신한다. 외부 배포는 인증·사용량 제한·서버 환경변수 설정을 별도로 검토한다.

## 현재 구현 (2026-10-06)
- 소식·찾기·발견·모임·프로필 UI. 장소·글·첨부 사진·모임은 서버 파일에 공유 저장. 닉네임·북마크·방문 메모·작성자 토큰은 브라우저 저장. 참가자는 자기 조건·투표만 변경.
- 카카오 Local 음식점·카페 조회 → 월계1동 경계 필터 → 실제 상호·업종·주소·전화·지도 링크. 5분 메모리 캐시. 각 업종 검색 최대 45개로 전체 동네를 망라하지 않는다.
- 찾기 및 모임 조건은 NVIDIA NIM으로 해석하고 최대 3개 조회된 가게 ID 선택. 서버가 ID를 검증하고 가게 설명은 조회 사실로만 구성.
- 가격·메뉴·분위기·대기·예약·시설·시간은 미확인. 조건 충족을 보장하는 추천이 아니라 추가 확인 후보. 조회 시각은 원본 갱신 날짜가 아니다.
- 지도: 월계1동만 컬러, 외부 흐린 흑백, 진한 경계, 실제 가게 핀. 내 위치는 요청 시 한 번 표시하며 외부 위치로 지도 이동하지 않는다. 위치/이동경로 저장 없음, 방문 인증 아님.
- 음성 입력(STT)/읽기(TTS)는 브라우저 기능. 실제 마이크 품질 검증 필요.
- 가상 초기 소식/가게는 새 UI에서 제거. 과거 시안 기록은 기존 localStorage 키에 보존하고 실제 정보용 별도 저장공간 사용.
- 기존 중간발표 `/midterm-demo.html`, 기존 React API 화면 `/?legacy=1` 유지. 기존 코드의 가격 추정값을 새 UI에서는 사용하지 않음.

## RAG 방향
현재는 카카오 조회 목록을 문맥으로 전달하는 검색 기반 생성 방식이며 벡터 DB는 없다. 향후 메뉴판/OCR·사장님 수정·사용자 제보를 출처·관찰일·검증 상태와 함께 저장한 뒤 조건 필터와 문서 검색을 결합한다. 부족한 사실은 RAG 자체로 해결되지 않는다.

## 공유 상태 (2026-10-06 갱신)
https://quiz-pound-flying-marc.trycloudflare.com 에서 모임·가게·AI API를 사용할 수 있다. 사용자가 외부 공유를 명시적으로 요청한 뒤 연결했다. 예전 invest-cooling 주소는 만료되었다.
`npm run server`와 `npm run share`를 켠 뒤 cloudflared tunnel --url http://127.0.0.1:4174 로 공유한다. gateway는 필요한 community/groups 라우트만 전달하며 기존 legacy API는 외부에 열지 않는다.
AI는 서버 프로세스 기준 시간당 100회/동시 2건 제한. 그룹 조건/투표는 참가자별 토큰, 후보 생성은 모임장만 가능. 재시작 시 사용량 카운터 초기화. 키는 프런트엔드에 넣지 않는다. PC·서버·터널 종료 시 접속이 끊기며 재실행 시 URL 변경 가능.

## 모임 공유 개선
- 모임 생성 → 12자리 코드/링크 참여 → 자기 조건 저장 → 모임장이 AI 후보 생성 → 자기 복수 투표. 참가자 정보는 3초 간격 갱신.
- 모임은 `.local-data/groups.json`에 저장(서버 단일 프로세스용, Git 제외). 참가자 토큰은 각 브라우저에 저장하며 응답에서 타인의 토큰은 제거한다. 로그인 기반 계정 복구는 아직 없음.
- 새 참여/조건 변경 시 후보와 투표 초기화. 추천 도중 변경됐으면 오래된 결과는 거절. 투표는 현재 후보 버전과 참가자 토큰으로 검증.
- 실제 두 브라우저에서 생성/참여/조건/AI 후보/2표 동기화/변경 초기화/새로고침/모바일 검사 통과. Node 테스트 8개 통과.
- 외부 공유 연결 전 검증은 localhost:5173에서 일반 창·시크릿 창으로 수행. 이후 공개 주소에서도 두 브라우저 공동 흐름 검증 완료.
- 카드의 출처/조회 시각 박스를 제거. 상세 하단에 기본 정보 출처만 표시. 실제 확인일/근거가 없는 정보에 검증 배지를 붙이지 않음.

## 새 장소와 동네 발견 · 2026-10-06 보완
