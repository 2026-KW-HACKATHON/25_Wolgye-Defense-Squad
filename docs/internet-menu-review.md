# 인터넷 메뉴 재검증

- 수집: `node scripts/collect-menus.mjs` (기존 인터넷 정보 유지)
- 백업 후 교체 수집: `node scripts/collect-menus.mjs --refresh`
- 백업 후 인터넷 메뉴만 비우기: `node scripts/collect-menus.mjs --remove`
- 검토: 관리자 로그인 → 사장님 공간 → 인터넷 메뉴 검토 → 출처 확인 → 승인/삭제.

광운대·월계동·석계역을 붙인 이미지/블로그 검색을 대조하고, 최근 2년 이내 검색 등록 결과 중 최대 2장을 분석한다. 사진 검증은 기존 OCR 호출에 포함한다. 상호·업종·한글·원화 및 블로그 출처 일치를 모두 통과한 항목만 자동 반영한다. 명확한 업종/통화 불일치는 제외, 불확실하거나 같은 메뉴가 다른 가게에 발견되면 검토 대기. 중복 판단은 이번 실행 후보끼리 비교한다.

검토 대기 자료는 `wolgye.menu_reviews`에만 저장하며 공개 장소 정보와 추천에 반영하지 않는다. 삭제 버튼은 검토 기록을 거절 상태로 보존한다. 승인할 때도 최신 가게 정보를 잠금 조회해 이웃·사장님 메뉴를 덮어쓰지 않는다. 사진 파일은 저장하지 않으며 API 제공자의 보관 정책과는 별개다.

인터넷 정보 백업은 Git 제외된 `.local-data/menu-backups/`에 저장한다. 게시/검색 등록일은 촬영일 또는 현재 가격 확인일이 아니다. 자동 검증은 오류 가능성을 줄이는 장치이며 일치 여부를 보증하지 않는다. 동일 메뉴를 가진 실제 지점도 검토 대기가 될 수 있다.
