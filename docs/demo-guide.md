# 중간발표 데모 사용법

`public/midterm-demo.html`을 더블클릭하면 설치·서버·API 키 없이 실행됩니다. 파일 하나만 보내도 동작합니다.
React 앱은 `npm ci` 후 `npm run client`로 열면 데모가 기본 화면입니다. 기존 대화 앱은 `http://localhost:5173/?legacy=1`에서 확인합니다.

## 2분 시연 순서

1. 모임 만들기 → 카카오톡 초대 미리보기. 실제 전송이 아닌 점을 설명합니다.
2. 시연 친구 2명 추가 → 내 조건 저장 → 식당 후보 찾기.
3. 골목반점에 투표 → 내 투표 저장 → 시연 친구들 투표 채우기 → 투표 마감.
4. 다녀왔어요 → 시연 메뉴판 사용 → 메뉴·가격 초안 보기 → 확인 체크 → 저장.
5. 함께 먹기 → 변경된 정보로 다시 추천받기. 골목반점 가격이 12,000원으로 바뀌어 만원 이하 후보에서 빠짐을 보여줍니다.
6. 나의 기여에서 가격 변경 기록과 배지를 확인합니다.

## 선택 시연

- 조건 입력 화면의 ‘5천원 · 20분’ 예시를 저장하면 조건을 임의로 완화하지 않고 후보 없음을 안내합니다.
- 참가자 닉네임을 바꿔 조건·복수 투표를 개별 입력할 수 있습니다. 입력 중 화면 전환 전 저장하세요.
- 동네 가게 → 가게 등록 제안 → 이름·위치·간판 사진. 확인 대기로 남고 추천에서 제외됩니다.
- 상단 ‘처음부터’는 확인 후 이 데모의 로컬 데이터만 초기화합니다.

## 실제 구현과 시뮬레이션의 경계

- 실제: 브라우저 내 상태 전환, 조건 필터, 선호 정렬, 복수 선택 투표, 가격 수정 반영, 수정 이력, 로컬 저장, 사진 미리보기.
- 시뮬레이션: 시연 참가자, 가상 가게와 가격·시간, 카카오 공유 카드, 메뉴 인식 초안, 기여 포인트.
- 미구현: 다른 기기와의 동기화, 실제 카카오 전송, OAuth, DB·사진 업로드, 사진 OCR, 도보 경로 조회, 기여 검증·운영 도구.
- 사진 원본은 서버로 전송하거나 로컬 저장소에 저장하지 않습니다. 메뉴판 미리보기는 현재 세션에서만 유지됩니다. 가게 등록 제안은 파일명만 저장합니다.
- 외부 폰트·이미지·API 요청 없는 독립 HTML입니다. 공유 링크는 같은 기기에 저장된 모임을 복구하는 용도입니다.

## 팀 공유 파일

- `docs/product-plan.html`: 핵심 기획·시스템 구성·API 검토안.
- `docs/midterm-report.html`: 첨부 양식에 맞춘 보고서. 항목별 복사·전체 복사·인쇄 지원. 팀원 이름은 직접 입력.
- `public/midterm-demo.html`: 독립 실행 데모.
