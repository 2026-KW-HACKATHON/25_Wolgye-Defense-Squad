# 사장님 홍보 기능 (MVP)

이 기능은 월계밥상 기존 화면 위에 네 가지 기능만 추가합니다: AI 홍보 대화(음성 STT 포함), 이미지·문안 제안 검토, 사장님 캠페인, 가게 상세 조회 성과 리포트. 기존 이웃 ‘소식’은 누구나 쓸 수 있고, 사장님 캠페인은 승인된 계정만 작성할 수 있습니다.

## 실행 설정

1. `npm install` 후 `npm run dev`로 실행합니다.
2. AI 기능(대화·STT·이미지 생성)을 활성화하려면 `.env`에 `OPENROUTER_API_KEY`를 설정합니다. (키가 없어도 화면과 캠페인·리포트 기능은 즉시 체험 가능합니다)
3. 화면 아래 **사장님 공간**에서 체험할 가게를 선택하면 별도의 복잡한 회원가입이나 관리자 승인 절차 없이 즉시 사장님 마케팅 공간(AI 대화, 콘텐츠 제안 검토, 캠페인 등록, 성과 리포트)으로 진입합니다. 필요할 때 언제든 '가게 변경 / 나가기'를 통해 다른 가게로 전환할 수 있습니다.

AI 연결은 [OpenRouter 채팅 API](https://openrouter.ai/docs/quickstart), [전사 API](https://openrouter.ai/blog/announcing-audio-apis/), [이미지 API](https://openrouter.ai/docs/guides/overview/multimodal/image-generation)를 사용합니다. 기본 모델은 `.env.example`에 적혀 있고 변경할 수 있습니다. API 키가 없으면 실제 AI 생성 요청은 오류를 보여줍니다. 이미지 생성은 API 비용이 들 수 있어 시간당 네 번으로 제한했습니다. 지금은 짧은 영상 대신 이미지 생성을 구현했습니다.

## 데이터와 해석

`POST /api/owner/views/:placeId`는 가게 상세 화면을 열었을 때 조회를 기록합니다. 같은 브라우저의 같은 가게 조회는 하루에 한 번만 셉니다. 브라우저에는 익명 조회 쿠키가 저장되고 서버에는 그날의 해시만 저장됩니다. 연령·성별·인원·금액·시간은 상세 화면에서 자발적으로 입력한 경우에만 집계하며, 입력하지 않으면 `미응답`으로 표시합니다. 금액은 5천 원 단위로 묶습니다. 리포트는 최근 90일의 플랫폼 내 상세 조회만 나타내며 매장 방문·매출·실제 구매 전환을 의미하지 않습니다. 쿠키를 지우거나 여러 기기를 쓰면 조회가 중복될 수 있으므로 엄밀한 순방문자 수는 아닙니다.

캠페인·계정·통계 데이터는 `.local-data/owner-marketing.json`에 저장됩니다. 이 파일은 배포 환경에서 지속 저장 공간과 백업이 필요합니다. AI 제안 이미지는 사장님이 검토·승인한 뒤 캠페인에 연결한 경우에만 소비자 화면에 표시됩니다. 관리자 승인은 화면의 승인 버튼을 누르기 전에 별도의 실제 소유자 확인 절차가 필요합니다.
